Задание 2

Найдите координаты вершины параболы y = x² - 4x + 3.

Введите в формате: x,y (например: 2,-1)

📖 Показать ответ

x₀ = -(-4)/(2·1) = 2, y₀ = 2² - 4·2 + 3 = 4 - 8 + 3 = -1. Вершина (2; -1).

Задание 7

При каком значении a парабола y = ax² - 4x + 1 имеет вершину в точке x = 2?

📖 Показать ответ

x₀ = -b/(2a) = 4/(2a) = 2 → 4 = 4a → a = 1.

Задание 8

📖 Показать ответ

y = 3·(-1)² - 2·(-1) + 5 = 3 + 2 + 5 = 10.

Задание 14

Парабола проходит через точки (0; 3), (1; 0) и (2; -1). Найдите коэффициенты a, b, c.

Введите в формате: a,b,c (например: 1,-4,3)

📖 Показать ответ

Из (0;3): c = 3. Из (1;0): a + b + 3 = 0 → a + b = -3. Из (2;-1): 4a + 2b + 3 = -1 → 4a + 2b = -4 → 2a + b = -2. Вычитаем: (2a+b) - (a+b) = -2 - (-3) → a = 1, b = -4. a = 1, b = -4, c = 3.

Задание 15

При каком значении a парабола y = ax² - 2ax + 3 имеет вершину в точке x = 1?

📖 Показать ответ

x₀ = -(-2a)/(2a) = 2a/(2a) = 1 для любого a ≠ 0. Ответ: любое a ≠ 0.
