Все необходимые формулы для работы с квадратичной функцией

1. Общий вид квадратичной функции

y = ax² + bx + c, где a ≠ 0, a, b, c ∈ ℝ

Пример: y = 2x² - 3x + 1 (a = 2, b = -3, c = 1)

2. Вершина параболы

x₀ = -b/(2a)

y₀ = c - b²/(4a) или y₀ = a·x₀² + b·x₀ + c

Пример: Для y = 2x² - 8x + 6: x₀ = 8/(4) = 2, y₀ = 2·4 - 16 + 6 = -2. Вершина (2; -2).

3. Ось симметрии

x = -b/(2a)

Пример: Для y = x² - 4x + 3: ось симметрии x = 2.

4. Дискриминант и корни

D = b² - 4ac

Корни: x₁,₂ = (-b ± √D)/(2a)

Пример: Для y = x² - 5x + 6: D = 25 - 24 = 1, x₁ = (5 + 1)/2 = 3, x₂ = (5 - 1)/2 = 2.

5. Канонический вид

y = a(x - x₀)² + y₀

где (x₀; y₀) — координаты вершины.

Пример: y = 2x² - 8x + 6 = 2(x - 2)² - 2

6. Фокус и директриса

Для параболы y = a(x - x₀)² + y₀ (a ≠ 0):

Фокус: F(x₀; y₀ + 1/(4a)) (при a > 0) или F(x₀; y₀ - 1/(4a)) (при a < 0)

Директриса: y = y₀ - 1/(4a) (при a > 0) или y = y₀ + 1/(4a) (при a < 0)

Пример: Для y = 2x²: x₀ = 0, y₀ = 0, p = 1/(8) = 0.125, фокус (0; 0.125), директриса y = -0.125.

7. Свойства коэффициентов

  • a > 0 — ветви вверх; a < 0 — ветви вниз
  • |a| — влияет на ширину параболы (чем больше |a|, тем уже парабола)
  • b — влияет на смещение вершины по оси X
  • c — точка пересечения с осью Y (0; c)

8. Теорема Виета

Если x₁ и x₂ — корни квадратного уравнения ax² + bx + c = 0, то:

x₁ + x₂ = -b/a

x₁·x₂ = c/a

Пример: Для x² - 5x + 6 = 0: сумма = 5, произведение = 6.
