Определение параболы

Парабола — это геометрическое место точек, равноудалённых от заданной точки (фокуса) и заданной прямой (директрисы). В декартовой системе координат парабола является графиком квадратичной функции.

Квадратичная функция имеет вид: y = ax² + bx + c, где a, b, c — действительные числа, a ≠ 0.

Свойства параболы

1. Направление ветвей

Если a > 0, ветви параболы направлены вверх. Если a < 0, ветви направлены вниз. Чем больше |a|, тем уже парабола (сильнее сжата к оси Y).

2. Вершина параболы

Вершина — это точка экстремума функции. Координаты вершины вычисляются по формулам:

x₀ = -b/(2a)

y₀ = c - b²/(4a) или y₀ = a·x₀² + b·x₀ + c

В вершине парабола достигает своего минимального значения (при a > 0) или максимального (при a < 0).

3. Ось симметрии

Парабола симметрична относительно вертикальной прямой x = x₀. Это означает, что для любой точки (x₀ + t, y) на параболе существует симметричная точка (x₀ - t, y).

4. Дискриминант и корни

Дискриминант D = b² - 4ac определяет количество точек пересечения параболы с осью X:

  • D > 0 — два корня (парабола пересекает ось X в двух точках)
  • D = 0 — один корень (парабола касается оси X)
  • D < 0 — нет корней (парабола не пересекает ось X)

5. Пересечение с осью Y

При x = 0, y = c. Таким образом, парабола всегда пересекает ось Y в точке (0; c).

6. Монотонность

При a > 0 функция убывает на интервале (-∞; x₀] и возрастает на [x₀; +∞). При a < 0 — возрастает на (-∞; x₀] и убывает на [x₀; +∞).

Фокус и директриса параболы

Парабола может быть определена через фокус и директрису. Для параболы y = ax² (вершина в начале координат):

Фокус: F(0; 1/(4a))

Директриса: y = -1/(4a)

Свойство: расстояние от любой точки параболы до фокуса равно расстоянию от этой же точки до директрисы.

Для параболы общего вида y = a(x - x₀)² + y₀:

Фокус: F(x₀; y₀ + 1/(4a)) (при a > 0)

Директриса: y = y₀ - 1/(4a)

Каноническое уравнение параболы

Параболу можно записать в виде: y = a(x - x₀)² + y₀, где (x₀; y₀) — координаты вершины. Это удобная форма для построения графика.

Чтобы привести общее уравнение к каноническому виду, нужно выделить полный квадрат:

ax² + bx + c = a(x + b/(2a))² + (c - b²/(4a))
